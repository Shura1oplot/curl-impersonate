# Вариант curl-impersonate для Lightpanda

## Цель

Собирать полный статический архив curl-impersonate для Lightpanda. Архив должен предоставлять профиль Chrome 146 через программный интерфейс и не применять профиль из переменных окружения до вызова Lightpanda.

## Границы

- Обычная сборка curl-impersonate сохраняет текущее поведение переменных `CURL_IMPERSONATE` и `CURL_IMPERSONATE_HEADERS`.
- Специальная сборка Lightpanda отключает только автоматическую обработку этих двух переменных в `curl_easy_init` и `curl_easy_reset`.
- Программный вызов `curl_easy_impersonate` остается доступным.
- Иные переменные окружения curl, включая параметры сетевого посредника и хранилища сертификатов, не затрагиваются.

## Критерии завершения

- Параметр сборки по умолчанию включен и сохраняет совместимость с исходным проектом.
- При отключенном параметре недопустимое значение `CURL_IMPERSONATE` не мешает `curl_easy_init` и повторному применению профиля Chrome 146.
- Полный статический архив собирается на macOS arm64 и проходит `make checkbuild`.
- Lightpanda связывается с новым архивом и проходит свои тесты при заведомо неверных значениях управляющих переменных окружения.
- Изменение исправления curl выполняется только после явного разрешения владельца согласно `AGENTS.md`.

## Состояние

Реализация завершена. Владелец разрешил точечное изменение `patches/curl.patch`. Специальная сборка с отключенной автоматической обработкой переменных прошла `make checkbuild`, проверки с неверным профилем и сборку полного статического архива для macOS arm64. Поведение обычной сборки сохранено параметром, включенным по умолчанию; этот вариант проверен конфигурацией, но не повторной полной сборкой.
